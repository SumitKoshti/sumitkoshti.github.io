# Sumit Koshti — Data Analyst Portfolio 2026

A recruiter-focused, static HTML/CSS/JavaScript portfolio.

## Files
- `index.html` — main website
- `style.css` — design and responsive layout
- `script.js` — navigation and project case-study modals
- `assets/` — put your resume and optional project images here

## Before deployment
1. Add your latest PDF resume as:
   `assets/Sumit_Koshti_Data_Analyst_Resume.pdf`
2. Verify the LinkedIn and GitHub URLs in `index.html`.
3. Replace/add live Power BI and GitHub project links when ready.
4. Open `index.html` locally to test.

## GitHub Pages
Create/push these files to a GitHub repository and enable Pages from:
Settings → Pages → Deploy from branch → `main` → `/ (root)`.

The site can then be shared as:
`https://<your-github-username>.github.io/<repository-name>/`
